# THU Labs

A collection of labs and course projects I completed at Tsinghua University, organized by course.

## Courses

### Programming Fundamentals

- [Robotgame](Programming%20Fundamentals/robotgame/): A C++ robot programming puzzle game with an online judge submission version and two interactive console versions.

### Programming Training

- [OJ System](Programming%20Training/oj-system/): An online judge built with FastAPI and Streamlit, featuring code evaluation, problem management, code plagiarism detection, and AI-assisted problem generation.
- [NetEase Spider](Programming%20Training/netease-spider/): A NetEase Cloud Music crawler with SQLite storage, a Django web interface, and lyric and comment analysis.

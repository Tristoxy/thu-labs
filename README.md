# THU Labs

A collection of labs and course projects I completed at Tsinghua University, organized by course.

## Courses

### Programming Practice

- [OJ System](Programming%20Practice/oj-system/): An online judge built with FastAPI and Streamlit, featuring code evaluation, problem management, and plagiarism detection.
- [NetEase Spider](Programming%20Practice/netease-spider/): A NetEase Cloud Music crawler with SQLite storage, a Django web interface, and lyric and comment analysis.

## Repository Structure

```text
thu-labs/

    └── netease-spider/
```

Each project contains its own README with setup and usage instructions. Run project commands from the corresponding project directory.
